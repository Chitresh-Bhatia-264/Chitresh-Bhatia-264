## 🧩 How My RAG Agents Think

```mermaid
flowchart LR
    A[📄 Documents] --> B[✂️ Chunk and Embed]
    B --> C[(🗃️ Vector Store)]
    D[💬 User Query] --> E[🔍 Retriever]
    C --> E
    E --> F[🧠 LLM Reasoning]
    F --> G{🛠️ Agent Tools}
    G --> H[✅ Grounded Answer]
    H --> I[📈 Evaluation]
    I -.-> B
```

<details>
<summary><b>🍰 How the pipeline works (click to expand)</b></summary>

<br/>

1. **Ingest** 📥: documents are cleaned, chunked and turned into embeddings.
2. **Retrieve** 🔎: the query is matched against the vector store for the most relevant context.
3. **Reason** 🧠: an LLM agent decides whether to answer directly or call tools with the retrieved context.
4. **Evaluate** 🌟: answers are scored for grounding and quality, and feedback improves retrieval and chunking.

</details>
